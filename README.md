# Moved to [catmando/diaconal-training](https://github.com/catmando/diaconal-training)

This repository exists only to keep old links working. The project was
renamed on 15 September 2026; GitHub Pages does **not** redirect a project
site after a rename (verified: the old URL returned 404 within seconds of the
rename), so this stub serves a redirect instead.

`index.html` and `404.html` are the same page. The 404 is the one that
matters: GitHub Pages serves it for any unknown path, so a link to a specific
file — `/rubric.pdf`, say — is carried across with its path, query and
fragment intact rather than dead-ending.

It also parks the old name, which a rename releases for anyone to claim.

Do not delete this repository.
